# 🏅 Olympic Analytics Engine
*Large-Scale Medal Data Processing with Apache Pig on Hadoop Ecosystem*

## 📊 Project Overview
A big data processing pipeline that performs comprehensive Olympic medal analytics across distributed datasets using Apache Pig for scalable data transformation and aggregation.

## 🚀 Data Processing Pipeline

### **Architecture & Workflow**
- **Cluster Orchestration**: Automated EMR cluster provisioning on AWS
- **Distributed Storage**: HDFS-based data lake for Olympic datasets
- **Data Processing**: Apache Pig scripts for parallel data transformation
- **Custom UDF Integration**: Python functions for advanced data cleansing

### **Analytical Operations**
- **Task 1**: Gold Medal Ranking & National Performance Benchmarking
- **Task 2.1**: Multi-Medal Analysis (Gold & Silver) with Country-Level Aggregation
- **Task 2.2**: Advanced Ranking with Data Quality Enforcement via Python UDF

## 🛠️ Technical Stack

### **Big Data Technologies**
- **Apache Hadoop HDFS**: Distributed file system for data storage
- **Apache Pig**: High-level data flow language for MapReduce
- **Python UDF**: Custom functions for null handling and data validation
- **AWS EMR**: Elastic MapReduce cluster management

### **Data Processing Capabilities**
- **Distributed Query Processing**: Parallel execution across cluster nodes
- **Data Aggregation**: Country-level medal counting and ranking
- **Data Quality Pipeline**: Null value replacement and validation
- **Performance Optimization**: Efficient data partitioning and processing

## 💡 Key Features

- **Scalable Analytics**: Processes Olympic datasets across distributed nodes
- **Custom Data Transformations**: Python UDF for advanced data cleansing
- **Multi-dimensional Ranking**: Country performance across medal types
- **Production-Ready Pipeline**: End-to-end data processing workflow

## 📈 Business Intelligence
- **National Performance Metrics**: Quantitative medal analysis by country
- **Data Quality Assurance**: Automated handling of incomplete records
- **Scalable Architecture**: Handles large-scale historical sports data
- **Actionable Insights**: Medal distribution patterns and competitive rankings
